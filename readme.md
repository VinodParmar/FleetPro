# FleetPro — Multi-Tenant Fleet Management
ASP.NET Core 10 MVC | SQL Server | EF Core 9 Code First | AdminLTE 3

## Quick Start
1. Update connection string in appsettings.json
2. dotnet ef migrations add InitialCreate --output-dir Data/Migrations
3. dotnet ef database update
4. dotnet run → https://localhost:5001
